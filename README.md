# Problem Solving (Python)

A collection of Python solutions for algorithmic problem-solving practice and coding challenges (including CodingBat problem sets).

---

## 📁 Repository Structure

The solutions are organized into modules and topical categories:

### 🔹 Module 1 (`python-module-1/`)
Contains beginner-to-intermediate problem sets focusing on foundational Python concepts:
- **Warmup-1 & Warmup-2**: Simple warm-up exercises
- **String-1 & String-2**: String manipulation and parsing
- **List-1 & List-2**: List/array operations and algorithms
- **Logic-1 & Logic-2**: Boolean logic and conditional flows

### 🔹 Module 2 (`python-module-2/`)
Contains advanced problem sets including recursion, data structures, and functional programming:
- **Warmup-1 & Warmup-2**: Simple warm-up exercises
- **String-1, String-2 & String-3**: String manipulation and parsing
- **Array-1, Array-2 & Array-3**: List/array operations and algorithms
- **Logic-1 & Logic-2**: Boolean logic and conditional flows
- **Recursion-1 & Recursion-2**: Recursive thinking and backtracking
- **Map-1 & Map-2**: Dictionary and mapping problems
- **Functional-1 & Functional-2**: Functional paradigms and lambda expressions
- **AP-1**: Applied algorithms and array processing
